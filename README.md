### 🪪 KYC — a four-service identity verification system

Four services, each answering exactly one question, and none of them knows about the others — a KYC API orchestrates the flow. Built for Brazilian ID documents.

| Repository | Question it answers | Stack |
|---|---|---|
| [lambda-doc-validation-service](https://github.com/floptadeu/lambda-doc-validation-service) | Is this document valid, and what does it say? | Python · AWS Lambda · Bedrock |
| [liveness-sdk](https://github.com/floptadeu/liveness-sdk) | Is there a live person in front of the camera? | TypeScript · MediaPipe · Web Worker |
| [lambda-screen-attack-detector](https://github.com/floptadeu/lambda-screen-attack-detector) | Is that face a person, or an artifact? | Python · AWS Lambda · ISO/IEC 30107-3 |
| [face-match-api](https://github.com/floptadeu/face-match-api) | Is it the same person as the document? | Python · ONNX · ECS Fargate |
